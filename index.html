プライバシーポリシー

最終更新日：2026年9月27日

「47都道府県ランキング」（以下「本サービス」）は、運営者が自ら管理する SNS アカウント（Instagram @japan47_ranking ほか、YouTube・TikTok の運営者アカウント）に、政府統計をもとにしたショート動画を投稿するための、運営者専用の投稿ツールです。本ポリシーでは、本サービスが取り扱う情報について説明します。

1. 取得する情報

本サービスは、運営者が自分のアカウントを連携する際に、各 SNS から次の情報を取得します。

  • 連携したアカウントの識別子（ユーザーID・アカウント名）
  • 動画を投稿するためのアクセストークン

本サービスは、運営者以外の利用者・視聴者の個人情報を取得しません。

2. 利用目的

取得した情報は、運営者のアカウントに動画を投稿し、投稿の状態を確認するためだけに使用します。

3. 保存と管理

アクセストークンなどの情報は、運営者が管理するコンピューター内にのみ保存し、第三者のサーバーには送信・保存しません。

4. 第三者への提供

取得した情報を第三者に販売・提供することはありません。ただし法令に基づく場合を除きます。

5. YouTube API サービスの利用

本サービスは YouTube API サービスを利用しています。本サービスを通じて YouTube を利用する場合、YouTube 利用規約（https://www.youtube.com/t/terms ）および Google プライバシーポリシー（https://policies.google.com/privacy ）が適用されます。

6. 連携の解除とデータの削除

連携はいつでも解除できます。

  • Google（YouTube）：https://security.google.com/settings/security/permissions
  • TikTok：TikTok アプリの「設定とプライバシー」→「セキュリティ」→「アプリの管理」
  • Instagram / Facebook：Facebook の「設定とプライバシー」→「設定」→「ビジネス統合」

連携を解除すると、本サービスはそのアカウントに投稿できなくなります。保存されている情報の削除を希望する場合は、下記の連絡先までご連絡ください。
